第 02 集Install

一条命令，两套界面。

支持 macOS 与 Linux 的 x86_64 和 arm64。程序装在 ~/.madecoding/bin。打开新终端后运行 madecoding。

  • macOS
  • Linux
  • x86_64
  • arm64
$ curl -fsSL https://madecoding.com/install.sh | sh

换目录用 MADECODING_INSTALL_DIR，装指定版本用 --version <tag>。

  1. 1

    点「复制」，拿到安装命令。

  2. 2

    粘贴到终端，按回车。

  3. 3

    运行 madecoding，选终端或网页。

终端
madecoding                  # 选择终端界面或网页界面madecoding tui              # 直接进终端界面madecoding web              # 直接开网页界面madecoding "修复这个测试"     # 带上任务直接开始

密钥和模型在网页界面的设置里配置，终端不挡登录。下一步看 配置，或去 购买独立服务器。
