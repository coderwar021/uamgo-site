本地运行

开始使用

支持 macOS 与 Linux 的 x86_64 和 arm64：

curl -fsSL https://madecoding.com/install.sh | sh

程序装在 ~/.madecoding/bin。打开新终端后运行 madecoding。 换目录用 MADECODING_INSTALL_DIR，装指定版本用 --version <tag>。 

madecoding                  # 选择终端界面或网页界面
madecoding tui              # 直接进终端界面
madecoding web              # 直接开网页界面
madecoding "修复这个测试"     # 带上任务直接开始

配置模型

两套界面读同一份 ~/.madecoding/config.toml，只需配置一次。密钥在 madeapi.com/keys。

[model_providers.madecoding]
base_url = "https://madeapi.com/v1"
env_key = "MADECODING_API_KEY"      # 只记变量名，密钥不写进配置
