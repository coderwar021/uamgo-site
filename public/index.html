uamgo code

终端与网页双界面的 AI 编码助手。

安装

curl -fsSL https://uamgo.com/cli/install.sh | bash

Windows PowerShell：

irm https://uamgo.com/cli/install.ps1 | iex

使用

装好后在终端输入 uamgo，会让你选择打开终端界面还是网页界面。也可以直接指定：

uamgo tui    # 终端界面
uamgo web    # 网页界面
uamgo "修复这个测试"    # 带任务直接开始

配置模型

两个界面共用一份配置，写在 ~/.uamgo/config.toml：

[model_providers.uamgo]
base_url = "https://你的网关/v1"
env_key = "UAMGO_API_KEY"

环境要求

网页界面需要本机已安装 Node.js 22.19 或更新版本；终端界面无额外依赖。
