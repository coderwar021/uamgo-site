终端与网页两套界面，共用一份配置。代码、会话和工作区都留在本地， 模型服务由你自己指定。

$ curl -fsSL https://uamgo.com/install.sh | sh

一条命令装好两套界面。都是自包含程序，不需要 Node.js，也不需要编译器。

两套界面

输入 uamgo 选择进入终端界面或网页界面，两者共享会话与配置。

本地运行

agent 在你的机器上执行，读写你的工作区。我们不托管你的代码和会话记录。

模型自选

接口地址、密钥与请求头全部可配置，接任何 OpenAI 或 Anthropic 兼容的网关。

开始使用

支持 macOS 与 Linux 的 x86_64 和 arm64：

curl -fsSL https://uamgo.com/install.sh | sh

程序装在 ~/.uamgo/bin，安装完会提示你把它加进 PATH。 换目录用 UAMGO_INSTALL_DIR，装指定版本用 --version <tag>。 

uamgo                  # 选择终端界面或网页界面
uamgo tui              # 直接进终端界面
uamgo web              # 直接开网页界面
uamgo "修复这个测试"     # 带上任务直接开始

配置模型

两套界面读同一份 ~/.uamgo/config.toml，只需配置一次。

[model_providers.uamgo]
base_url = "https://你的网关/v1"
env_key = "UAMGO_API_KEY"      # 只记变量名，密钥不写进配置

[model_providers.uamgo.extra_headers]
"x-tenant" = "acme"
