Local coding agent

模型跟着你的仓库走。不进云端。

终端与网页两套界面，共用一份配置。代码、会话和工作区都留在本机。 需要独立 GPU 时，另开一页按小时购买。

Install ticket001
$ curl -fsSL https://madecoding.com/install.sh | sh

一条命令装好两套界面。自包含程序，不需要 Node.js，也不需要编译器。

安装

macOS 与 Linux，x86_64 和 arm64。装完运行 madecoding，自己选终端或网页。

打开安装页 →

模型部署

按小时买独立服务器。支付后签发我们的地址和密钥，源站不交给买家。

打开部署页 →

配置

两套界面读同一份 ~/.madecoding/config.toml。密钥只写环境变量名。

打开配置页 →
